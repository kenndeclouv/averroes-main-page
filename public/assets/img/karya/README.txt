FOLDER FOTO KARYA & KEGIATAN SANTRI AVERROES (SLIDER / CAROUSEL)
====================================================================
Lokasi: public/assets/img/karya/

FITUR OTOMATIS:
- Masukkan foto apa saja dan berapa saja (misal screenshot portofolio web, mobile app, desain grafis, poster, foto booth, coding bootcamp, dll).
- Website OTOMATIS memuat semua foto ke dalam slider secara dinamis tanpa perlu edit kodingan lagi!
- Format yang didukung: .jpg, .jpeg, .png, .webp, .avif

PENAMAAN FILE (Bebas! Otomatis dijadikan judul card foto):
- Contoh: `project-web-mobile.jpg`   -> otomatis tampil judul "Project Web Mobile"
- Contoh: `design-branding-ui.png`   -> otomatis tampil judul "Design Branding Ui"
- Contoh: `01-aplikasi-kasir.webp`   -> otomatis urutan 1, judul "Aplikasi Kasir"
- Contoh: `02-desain-kemasan.jpg`    -> otomatis urutan 2, judul "Desain Kemasan"
- Atau sekadar angka: `1.jpg`, `2.jpg`, `3.jpg`, dst.

Rekomendasi rasio gambar:
- Landscape (16:10, 16:9, atau 4:3), misal resolusi 800x520px atau 1200x800px.
- Jika folder ini masih kosong, website otomatis menampilkan foto dokumentasi placeholder yang rapi tanpa error.
