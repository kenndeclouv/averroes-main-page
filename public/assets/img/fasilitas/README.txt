FOLDER FOTO FASILITAS AVERROES (SLIDER / CAROUSEL)
======================================================
Lokasi: public/assets/img/fasilitas/

FITUR OTOMATIS:
- Masukkan foto apa saja dan berapa saja (misal 4, 8, atau 20+ foto fasilitas).
- Website OTOMATIS memuat semua foto ke dalam slider secara dinamis tanpa perlu edit kodingan lagi!
- Format yang didukung: .jpg, .jpeg, .png, .webp, .avif

PENAMAAN FILE (Otomatis dijadikan judul card foto):
Nama file yang kamu berikan akan langsung dijadikan judul di card slider:
- Contoh: `lab-komputer.jpg`             -> otomatis tampil judul: **Lab Komputer**
- Contoh: `asrama-santri.jpg`            -> otomatis tampil judul: **Asrama Santri**
- Contoh: `kamar-mandi-bersih.jpg`       -> otomatis tampil judul: **Kamar Mandi Bersih**
- Contoh: `gazebo-belajar.jpg`           -> otomatis tampil judul: **Gazebo Belajar**
- Contoh: `lapangan-futsal.jpg`          -> otomatis tampil judul: **Lapangan Futsal**
- Contoh: `01-perpustakaan-digital.webp` -> urutan 1, otomatis tampil: **Perpustakaan Digital** (angka urutan di depan dibersihkan)

Rekomendasi rasio gambar:
- Landscape (16:10, 16:9, atau 4:3), misal resolusi 800x520px atau 1200x800px.
- Jika folder ini kosong, website otomatis menampilkan foto placeholder rapi tanpa error.
